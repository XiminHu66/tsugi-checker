01ADD TITLE

添加追更作品

打开仓库中的 config/library.json，复制一个条目并填入作品详情页 URL。建议使用“作品详情 / 目录页”，不要使用站内搜索页。

{
  "id": "my-title",
  "type": "novel",
  "source": "bilinovel",
  "title": "作品名",
  "url": "https://…",
  "enabled": true
}
