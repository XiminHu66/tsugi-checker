CONFIGURATION

设置说明

保持前端简单，把作品管理和抓取逻辑留在仓库配置里。

01ADD TITLE

添加追更作品

打开仓库中的 config/library.json，复制一个条目并填入作品详情页 URL。建议使用“作品详情 / 目录页”，不要使用站内搜索页。

{
  "id": "my-title",
  "type": "novel",
  "source": "bilinovel",
  "title": "作品名",
  "url": "https://…",
  "enabled": true
}
02SOURCES

03DELIVERY

每日更新流

工作流每天运行并把新章节写入 data/feed.json 与 data/feed.xml。Atom 地址可直接加入 Feedly、FreshRSS、Reeder 等阅读器。

04CONTENT & THEME

公开内容与主题

站点最新与 ACG 新闻源配置在 config/content.json。明 / 暗主题与“已读 / 未读”状态都保存在当前浏览器 LocalStorage。
